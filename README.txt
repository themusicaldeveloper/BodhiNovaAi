HOW TO HOST
-----------
GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html and the assets folder.
3. Open Settings > Pages.
4. Choose "Deploy from a branch".
5. Select main branch and /root.
6. Save.

You can also upload these files to Netlify, Vercel, cPanel, Hostinger, or any normal static web hosting.
